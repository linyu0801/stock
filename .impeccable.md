# Impeccable Project Context

## Design Context

### Users
Single power user (the owner). Taiwan stock investor doing **post-market review** (盤後復盤): checking daily gainers/losers, managing watchlist groups with notes and sublabels, reading candlestick charts with MA/BIAS indicators, running backtests. Primarily desktop (large screen, evenings); phone use is occasional glance-checking — mobile must be readable and navigable, not touch-optimized for heavy editing.

### Brand Personality
Modern, light-footed, with personality (現代輕快・有個性). Professional data clarity without terminal-style coldness. Three words: **precise, nimble, personal.**

### Aesthetic Direction
- Evolution of the existing UI, not a rebrand. Keep: dark base theme, violet primary (#7B6EF6 family), Taiwan market convention **gain = red (#FF4560), loss = green (#00C896)** — never swap.
- Add a **light theme**; **dark stays the default**. Theme toggle persisted in localStorage. Light palette must be derived (tinted neutrals toward violet), not inverted.
- Numbers are the protagonist: tabular figures everywhere data aligns.
- Comfortable review density (not intraday-terminal cramming); charts get room.
- Anti-references: Bloomberg-terminal austerity; generic AI dashboard (cyan-on-dark glow, gradient text, side-stripe cards).

### Design Principles
1. **Desktop is home**: ≥1024px gets master-detail (watchlist + inline stock detail); mobile adapts by navigation, not amputation.
2. **Numbers first**: hierarchy built around price/change readability; tabular-nums; color + sign (never color alone).
3. **Keep the identity**: violet primary, red-gain/green-loss are fixed brand facts.
4. **Light touch of motion**: 150–250ms ease-out state transitions only; no decorative animation.
5. **Both themes are first-class**: every component checked in dark AND light before done.
